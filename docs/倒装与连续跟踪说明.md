# 倒装180度与连续跟踪调整

基于877ea3d7d0dea716a608ec72ccbca83b247d25aa，统一倒装安装坐标并增加有界的短暂漏检保持。

## 行为

相机倒装180度，图像仅旋转一次后识别；原始标定文件不覆盖，转换后的光线角度以正画面右yaw正、上pitch正。十字使用转换后的标定主点。颜色选择、调试显示、原卡尔曼跟踪、UART2 /dev/ttyS2 115200、48字节V2/CRC和IMU保持。STM32不在本仓库改动范围。

亮灯芯与颜色区域分开提取、灯条去重；验证彩色边缘，拒绝白色/错误颜色。连续两次匹配后，最多允许2帧且不超过60ms保持最后测得中心，超时目标无效。HOLD不会无限预测。屏幕及[TRACK]日志区分真实测量与保持；48字节无新增字段，target_valid包括有界保持。

MAIX_UART_TEST=1仍可执行原20帧模拟测试；正常运行不会自动发模拟目标/IMU。运行脚本清除此变量。RMIC_ENEMY_COLOR=red/blue可选择跳过菜单；不设置时保留触摸菜单。RMIC_CAPTURE_DIR是可选诊断录像目录，最多150帧PNG，开销大，正常控制不启用。

## 编译与运行

标准MaixCDK工程布局、main/CMakeLists.txt保留，按匹配的MaixCDK环境构建。

当前相机另提供本机编译入口：

```sh
cd /root/26rmic-main
make -f tools/native/Makefile -j1 all test
sh tools/native/run.sh --check-mount
sh tools/native/run.sh
```

本机入口依赖该设备MaixPy4.12.5的C++导出库、Python3.13、OpenCV4.11，以及既有/root/dist/RMIC26_release/dl_lib和/root/rmic26_mount180/sdk_include。SDK_INCLUDE、MAIX_RUNTIME、LEGACY_LIB_DIR可覆盖路径。它是针对已安装运行库的本机备选入口，不能当作跨固件通用二进制。设备可用内存约446MiB，没有swap，使用-j1且编译前停止摄像头程序。

原始标定默认/root/camera_intrinsics.yml，不覆盖。MaixVision连接设备后执行run.sh，选择敌方颜色并CONFIRM。一次只运行一个视觉程序。

## 测试范围

mount180_test：真实OpenCV旋转、非居中主点、四象限符号、48字节角度/CRC、IMU字段及丢目标。
tracking_test：红蓝灯条、错误颜色/白色拒绝、白灯芯彩边、短时保持、60ms边界、真正丢失和tick回绕。

此前实机150次读取中142次目标有效，不能等同逐帧检测精度；仍有少量漏检或关联失败。回放稳定装甲板片段和无目标背景片段也验证过，但不能保证所有背景都不误检。方向控制仍需实车逐模式确认。

启动器会暂时停止系统菜单及其自动拉起，释放显示设备，视觉程序退出时恢复菜单；不会更改系统开机配置。--check-mount不占用显示，不停止菜单。
