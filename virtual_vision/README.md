# MaixCAM2 独立图像检测与像素跟踪程序

本目录保存 2026-11-07 确认的蓝光反射容忍版，独立构建和运行。输出图像检测框、像素轨迹与 MaixVision 预览，不包含姿态求解、瞄准输出、串口控制或执行器控制。本目录不接入仓库根目录现有程序的运行链路。

## 本版变化

- 普通与倾斜灯条配对共用暗色内区检查。
- 容忍蓝色灯光照亮的黑色面板，结合红/绿通道上限、内部亮度和两根灯条的亮度对比判定。
- 总暗色采样比例至少 85%，每行至少 70%。
- 保留禁止跨第三根同方向灯条配对。
- 启动检查忽略已经退出且没有可执行映像的进程，避免重启时误报摄像头占用。
- 可通过 `VISION_DIAGNOSTIC_DIR` 选择保存叠加前的诊断图像，默认关闭。

核心逻辑见 `main/src/ColorContourDetector.cpp` 的 `blackInteriorBetween`。采样跟随灯条方向，避开端点与边缘光晕；红色目标原有检测逻辑保持不变。

## 构建与运行

本程序使用设备上已有的 MaixCAM2 SDK、OpenCV、MaixPy 运行库及 AX 库；不是电脑端直接运行程序。先停止已有摄像头程序，备份设备上的同名项目目录，然后将本目录内容放到 `/root/MaixCAM2_virtual_vision_20261107`。

```sh
cd /root/MaixCAM2_virtual_vision_20261107
make -B -j1 all test
sh start.sh
```

前台按 Ctrl+C 停止。`stop.sh` 只停止 `live.pid` 记录的后台实例。保持 MaixVision 连接即可接收预览。详细 SSH 与后台运行步骤见 [SSH_运行说明.md](SSH_运行说明.md)。

## 参数与验证

`camera.conf` 保留已使用的固定曝光、增益、180° 图像旋转和预览配置。

- 已在 MaixCAM2 上完成编译；五项回归测试通过。
- 额外开启 `RMIC_TILT_PAIRS=1` 的检测测试通过。
- 现场原始图像回放识别出中央目标 1 个，左右相邻可疑组合被拒绝。
- 设备启动验证中实时预览约 27–30 帧/秒，固定曝光稳定。
- 最后启动验证时当前视角检测数为 0，实时相邻目标误配率尚未完成验证；单张照片不能证明其他场景均无误配。

本目录只包含源码、脚本、测试与随原交付包提供的第三方头文件，不包含设备可执行文件或现场照片。
